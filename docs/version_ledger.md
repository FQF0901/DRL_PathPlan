## 0. Root cause 状态（诚实版）

- **已定位（机制层，证据充分）**：phase3 原始配方（**每轮从基座复位** + **仅失败窗口数据** + **无锚**）对 37 个全局 MoE 张量施加"无安全方向"的更新 ⇒ 每轮净退化（−30…−48；z 3.4–5.2）。修复机制（**R1 顺序续训 / R4 基座护栏 / keep-best**）已落地（350 tests）且 ③ 真循环验证护栏正确拦停。
- **未完全定位（因果层）**：窗口**"双峰"**（r2/r3/r5 正 vs r1/r4 负）的**确切成因**。现有两个**后验**判别子（未经前瞻验证）：
  1. **采集学生性能档**：采集学生闭环 ≤0.254 → 正模态；≥0.268 → 负模态（7–8/8 一致，含混合臂）；
  2. **负簇窗口内容主导**：混合臂中 r1/r4（40,133 行）压过 r2/r3/r5（60,100 行）。
  - 混杂：混合臂同时把**窗口:锚行比 5.4%→21.8%**（锚稀释），与判别子 2 未分离。
