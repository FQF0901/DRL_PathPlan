# Stage B phase3（DAgger）归因分析 & RL 基座修复方案

**定位**：deepwork P2 交付（canonical 分析 + 修复设计）。P3 判别实验（含 **E-β′ 强锚：0.436，+10.8pt**；复现通过）与 **G1/G2 两轮独立复核**均已并入本版；**RL 基座已定档 = E-β′**。
**证据纪律（G1 复核后）**：评测为**确定性**（`eval_runner` `deterministic=True`，动作=action_mu），无评测噪声，统计用配对 McNemar；严格区分 **单轮步 / 相邻轮差**、**可训集 / 变化集**、**缩放前 lr / 实际 lr**；"周期 2"仅指**失败构成**（success 是平平台）。

## 0. TL;DR（结论先行）

1. **phase3 从未净增益**：5 轮闭环 0.232/0.242/0.268/0.254/0.262，**全部低于入口基座 0.328**（配对 z=5.18/4.84/3.35/4.22/3.67）。若按配置文档的 guard 语义（对比 phase2 基座），**r1 就该停机**。
2. **"迭代"名不副实**：每轮**从同一基座重新开始**（无权重累积）＋**只用当轮窗口**（无数据聚合）→ 5 轮 = 同配方的 5 次独立试验，不是一条学习轨迹。
3. **参数范围事实**：phase3 只训 **37/135 张量 = `plan_head.moe` 全块**（536,137/1,149,667 = **46.6%**），与 phase2-specific **完全同集**；phase1 另训 54 个（**与 37 零交集**）；**st_gnn（20.5%）、value、ego_next 在 B 全程冻结**。→ **范围本身不能解释退化**（同样的 37 张量在 phase2 曾 +5.2pt）。
4. **P3 判别实验结果（终版）**：无锚/弱锚包络内全部显著退化（net −33…−48，z 3.7–5.2）；**强锚（mild=1.0）翻案**：E-β′ = **0.436（+10.8pt，net +54，z=4.66）**——**首个显著超过基座（且超旧代 0.396）的配方**；弱锚（0.1）与 idm 教师不缓解；**顺序续训（R1）唯一忠实步 ≈ 基座**（0.318，z=0.47）；链后续步为 **stale-window 模拟**（不作为"趋势定律"）；**对照消融**：纯 expert5k **0.290（−19）** —— 增益来自**窗口×强锚交互**；**泛化扫描（r1–r4）**：r2 +49 / r3 +52 复现 r5 +54，但 r1 −51 / r4 −27 ⇒ **配方为窗口条件性（双峰）**（正模态簇 0.426–0.436；每窗口单训练种子、seed 与窗口绑定）；③ 真循环在 r1 触发 base 护栏停机（0.226，护栏正确工作）；③ fresh-r1（独立采集、同采集学生）复现 r1 负模态 ⇒ 采集抽样下稳健。
5. **机制与作用域**：无锚/弱锚包络内 3 类数据落在同一损伤带（0.236–0.262）且训练损失下降而闭环下降 ⇒ 37 张量全局读出的"安全更新方向"取决于**是否与大规模专家数据同训**；强锚（w=1.0）把策略拉回专家流形（action loss 0.0205→0.0134）并**反超基座** ⇒ 修复方向 = **强锚 + R1 顺序续训 + R4 护栏 & keep-best**，但**落地须把"窗口筛选/混合"作为显式变量**（扫描双峰：正模态 0.43–0.44 / 负模态 0.23–0.27；③ 真循环因 r1 负模态被护栏正确拦停——见 §8.4）。
6. **RL 基座**：**定档 = E-β′（0.436；复现已验；清单 `runs/_refs_rlbase/`）**，**附窗口条件性标注**（同配方在 r1/r4 窗口为负，§8.4）——作为 RL 初始化仍为当前最优可用权重；**L2（0.328）保留回退**（警示：**全局读出脆弱 → RL 侧 KL 锚/keep-best 必须上**）。
   **适用域框（防超域）**：以上结论仅在"37 张量 / 5ep@1.5e-4 / chain 0.2 / 窗口权 1.0 / 锚权 {0, 0.1, 1.0} / idm 变体"的**实测包络**内；未测：chain-0、lr≠1.5e-4、锚权中间档、真循环 >1 步、多种子、r1–r4 窗口/其他锚目录。

## 2. Q1 — phase3 有哪些参数参与训练？整个 net 都参与吗？

**结论：只训 37/135 个张量，其余 98 个（含 st_gnn、value、ego_next）逐元素零变化。**

### 2.1 三套范围（代码 + 运行 + ckpt 三重实证）

| 配置 | 冻结前缀（`pipeline/stages.py:2289-2307,3185`） | 可训 / **变化** | 参数量 |
|---|---|---|---|
| **B-phase1 primary** | `st_gnn.` `value.` `moe.experts.` `moe.router.` | 60 / **54** | 352,450（30.7%） |
| **B-phase2 specific** | `st_gnn.` `value.` `encoders.` `mem_encoder.` `fusion.` `norm.` `ego_next.` `moe.primary.` `policy.` | 37 / **37** | **536,137（46.6%）** |
| **B-phase3 specific_only** | 直接复用 phase2 清单 | 37 / 37 | 同上 |
| （phase3 `all`） | 无冻结（133 可训；且有崩坏历史，见 §7） | — | — |

- **37 的完整枚举**：`plan_head.moe.experts.{0..7}.{0,2}.{weight,bias}`（8 专家 × 4 = 32；每专家 `Linear→GELU→Linear`，token hidden=128、expert hidden=256）+ `plan_head.moe.router.{0,2}.{weight,bias}`（4）+ `plan_head.moe.residual_scale`（1）。
- phase1 可训 60 中 6 个未变化：`ego_next×4`（损失未激活）、`residual_scale`（phase1 MoE 关 → 无梯度）、`log_std`（不进损失）→ 故"变化 54"。
- **B 累计变化 = 91/135 张量、888,587/1,149,667（77.3%）**；54 与 37 **零交集**。
- net 共 133 参数张量 + 2 buffer（`policy.action_low/high`）。

### 2.2 用户问到的名字

- **`primary` / `specific`**：在本仓是**模块名**（`plan_head.moe.primary` 常开主分支 / 8 个 `experts` 专家块），同时也是**阶段名**（B-phase1 "primary 段" / B-phase2 "specific 段"）——同名不同物。phase3 冻结的正是 `moe.primary`，训练的是 experts+router。
- **`mem`**：`net.mem.MemBank`，**只读激活**（net 不更新它，更新由 env 完成）；phase1 训练的 `mem_encoder.{ego,od,others}_attn.*`（24 张量）是它的编码器。
- **`mem_copy`**：**代码/ckpt 中不存在该模块或参数**；实际对应 rollout 内的 `encoded["mem"].clone()`（激活张量，无梯度、无 EMA/target net）。

### 2.3 训练口径细节（引用时勿错）

- 日志打印 `lr=3.00e-04` 是**缩放前**；`specific_only` 下 base 组为空 → 37 张量**实际 lr=1.5e-4**（`trainer.py:509-511`）；phase1/2 的 specific 段 lr=3e-4（无缩放）。
- 步数预算：phase3 ≈ **100 步**（20,015 行 /宏 batch 1024 × 5 epoch，micro 256）× 1.5e-4；phase2-specific ≈ **3,520 步** × 3e-4 → lr×steps ≈ **72:1**。

## 3. Q2 — 为什么 phase3 的效果范围比不上 phase2？

**先说清"比不上"在哪：**

| | 相对其入口的增益 |
|---|---|
| phase3（5 轮，全部） | **−0.060 / −0.086 / −0.060 / −0.074 / −0.066**（0.232–0.268 vs 0.328）→ **从未为正** |
| phase2（新代码代，3 个样本） | L2: **+0.052**（z≈3.15）｜1105 链: **−0.062**｜E1: **−0.052** → **方向不稳** |
| phase2（旧代码代） | 旧 primary 0.274 → 0.396 = **+0.122**（TestA 位级复现） |

**范围（张量数）不是解释**：同样的 37 张量，phase2 在 L2 链 +5.2、phase3 每轮 −6～−10。真正的差异在**数据 / 目标 / 步幅 / 起点语义**四层：

### 3.1 数据分布（结构性 coverage gap）
- phase2-specific：**360,501 行**（expert5k 全分布）+ worst-50% 硬加权（hard 1.0 / mild 0.1）。
- phase3：**~20k 行/轮 = 仅失败窗口**（1000 失败 episode 的终止前 10s，20 帧/窗口；只含 out_of_road/collision——**max_step/arrive_dest 覆盖为 0**）；**无锚、无跨轮聚合**。
- 跨轮 spec 并集 3075、交集仅 5 → 每轮是**一组全新的失败场景**。

### 3.2 教师/标签语义不匹配（此前遗漏的混杂）
- expert5k（BC 数据）：`expert=idm` 采集。
- phase3 窗口标签：**`pure_pursuit`**（收集器默认，帮助文本自述"动作语义不同"）→ 分布 + 教师同时变。

### 3.3 目标函数差异
- phase2-specific：`action 1.0 + traj_aux 0.1 + load_balance 0.01`。
- phase3：`action 1.0 + action_chain 0.2 + load_balance 0.01`（`action_chain` 项在 phase2 **不存在**；traj 被禁）。

### 3.4 步幅与位移几何（G1 复核实测）
- 位移范数：`||Δ(phase2)||=17.34` vs 各轮 `||Δr_k||=4.07/4.29/4.21/4.37/4.29`（≈1/4）。
- **单轮步**（基座→r_k）：max|Δ| = 0.01556/0.01563/0.01657/0.01614/0.01617；mean = 0.00485/0.00511/0.00503/0.00521/0.00514；**相邻轮差 mean 仅 0.0017–0.0023（更小）**。
- 方向：`cos(Δphase2, Δr_k) = 0.010–0.015`（**近正交**，符号一致率 50.4%）；`cos(Δr_j, Δr_k) = 0.81–0.96`（**五轮彼此高度同向**）。
- 结论表述：**每轮 = 一次"≈1/4 量级、近正交于 phase2、彼此同向"的重复基座位移；既不抵消、也不累积**。（此前"来回抵消"推断已由 G1 证伪。）

## 4. Q3 — 数据协议：fail case 来自 train 集？闭环来自 eval 集？

**是（且有硬保障）；一处 nuance 与一处统计口径：**
- **fail case 来自 train 侧**：采集池 `env/specs/scenarios_train_5k.json`（== expert5k 的场景集）；三道守卫（`tools/make_dagger_pools.py:66-73`、`tools/dagger_collect.py:879-908`、`pipeline/stages.py:286-306`），每轮 provenance `isolation_guard.overlap=0`。
- **闭环性能来自 eval500**：`env/specs/scenarios_eval500.json`，且**固定 (id,seed)**（符合"口径统一"要求）。
- **nuance**：A/B 的 val-dir（`datasets/BTC20260927-1734_expert500val`）与 eval500 为**同一批 (id,seed) 场景**（开环专家数据做 val）。当前无选择性偏差（`final.pt` 为末 epoch，无 best-select）；**未来若引入 val 早停，需要物理隔离，否则泄漏**。
- **统计口径**：20,015 行 ≈ 1000 episode × 20 帧（帧间强相关，非独立样本）；跨轮 spec 重叠极小 → 不要用行数做独立样本推断。

## 5. Q4 — "东墙西墙"根因

### 5.1 机制链（证据级）
```
窗口单源数据（教师/目标/步幅混杂）
   ↓ 每轮从基座独立微调
全局模块（37 张量 = top2 路由 + 全局 residual_scale）的全局位移
   ↓
对所有输入的行为同时改变 → broken ≫ fixed（55–67 vs 18–25）→ 失败构成周期 2
```
- 翻牌矩阵（vs 基座）：fixed/broken/net = 19/67/−48、18/61/−43、25/55/−30、20/57/−37、24/57/−33 —— **每轮都是"打破多于修复"**，且修复集合几乎不重现（五轮并集 3075 / 交集 5）。
- **数据↔行为的闭环**：采集数据的 coll 占比（4.4/17.9/7.7/12.5/5.8%）由**前一轮 student 的行为**决定（秩相关=1）；而训练输出的 coll 又与本轮数据 coll 近完美反相关 → "东墙西墙"最干净的数字化表达。
- 候选**全局激进旋钮**（**降权**：单旋钮叙事不足——E-β 出现 off-road 0.718 而 coll 0.032，说明不止一个行为维度在动）：`speed_ratio` 与 coll 率秩一致（0.425–0.483；base 0.430），留待正确配方下复验。

### 5.2 MoE 到底奏不奏效？
- **"MoE 未奏效"有实证**：phase2 结束时 8 专家负载**近均匀**（expert_load 0.113–0.128，cv=0.116，gate_entropy=0.975）→ 近似**等权平均 ≈ 一个更宽 MLP**；每专家更新也均匀（1.0–1.7，无专化）。r1 窗口分布下 cv 升至 0.479（但属训练批统计）。→ 结论：**不是"路由坏了"，而是"专家在此配方下没有形成专门化"**。
- `residual_scale`：1.0 → 1.0395（phase2）→ ≈1.046（各轮）——一个**全局标量**被推高，正是"全局干预"的缩影。

### 5.3 "参数分布不合理"命题：在此 net 上**不成立为该形态**
- net 仅 **1.15M 参数**；`plan_head` 占 63.1%、MoE 块 46.6% **且全部可训**；而承载"难场景"的 `st_gnn`（20.5%）与全部 encoders 的其余部分在 B 全程冻结。
- 因此"难模块参数少"不是现状描述；更准确的问题 = **可训旋钮集（MoE）是否适合修正残余失败**（证据倾向：不适合单独使用）。

### 5.4 要不要 deformable / transformer / flash attention？
**现阶段不建议**（按证据排序）：
1. **flash atten = 纯速度**（不修精度；且当前瓶颈不在注意力算力）。
2. **deformable/transformer = 大改**，需要"表示瓶颈"证据支撑；现有证据（成功/失败集中在行为层、MoE 全局旋钮效应、数据层混杂）指向**配方与数据**，不是表示容量。
3. 便宜且可判别的路径优先；**已判**：弱锚（0.1）、idm 教师均不缓解；R1 唯一忠实步 ≈ 基座；**强锚（E-β′）= 窗口条件性双峰**（§8.4）；**待判**：chain-0、lr 缩放、跨轮聚合——单项 ~1–3min 训练 + ~6–7min 评测。
4. 若上述修复后仍无量级改善，再考虑"扩大可训范围（分级低 lr）"乃至结构级改动。

## 6. Q5 — 要不要跑 r6–r10？

**不建议（在当前配方下）**：
- 每轮从基座独立微调、数据不聚合 → r6–r10 = 同分布的另 5 次试验；轮间 success 差异本身不显著（|z|≤1.6），预期继续平平台（失败构成继续周期 2）。
- **guard 语义问题**：配置文档（`config/train.yaml:110-112`）写"相对 phase2 基线"，实现只与**上一轮**比（`phase3_loop.py:237-279`，r1 无对比）。按文档语义，**r1（0.232 < 0.328−0.05）就该停**，r2–r5 不会发生。→ **R4 正是把实现修回文档意图**。
- 若你仍想看曲线：列为 E3 备选（预计 ~2h，产出 = 同平台的更多点），优先级低于 E-β/E-γ/E4。

## 7. Q6 — 其他洞见（清单）

1. **guard 口径**：只逐轮比较 + 无 keep-best → 全程低于基座也继续跑；"末轮 δ=−0.008 未触发"**不可**当"安全"证据。
2. **DAgger 经典三要素全缺**：数据聚合 ❌ / 从上一轮续训 ❌（R1 修）/ keep-best ❌（R4 修）。
3. **anchor 现成未用**（默认关）：窗口行 + expert5k 锚行（mild 0.1）一个开关即可验证。
4. **教师对齐**：BC 数据=idm，phase3 窗口=pure_pursuit；这是**未被任何文档记录的语义切换**。
5. **r1 独有 178 行 `train_weight=0`**（`filter_reason=stuck`），r2–r5 为 0——采集过滤行为随学生变化。
6. **coverage gap**：窗口只含 oof/collision（无 max_step/arrive_dest），与 phase2 全分布结构性不同。
7. **退化分布**：集中在 medium/hard（easy r1 0.393 < base 0.454；r5 0.464≈base）。
8. **val==eval 同批 (id,seed)**：当前无泄漏（末 epoch，无 best-select）；**引入早停前必须隔离**。
9. **配置注释"0.032/0.038 必崩"未找到 artifact**（G1 全 runs/ 扫描）→ 引用时标注"未复核断言"。
10. **旧代码代 final（0.396）**：本目录最高闭环；但为旧代际（含旧 MoE/聚类 router 机制、无 LD；|dθ| 0.0076），与新代控制风格不同——作为 RL 基座须先做风格核对。
11. **"period-2"动力学**：数据↔行为的自激循环（前轮学生→本轮数据→本轮模型），修复数据侧（锚/聚合）应能打破。
12. **吞吐事实**：训练 49–51s/轮（!），瓶颈在采集（16–21min）与评测（6–7min）——**配方迭代成本很低，值得多做变体**。
