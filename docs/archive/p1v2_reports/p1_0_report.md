## 1. 摘要（四问四答）

1. **P1 起点模型** = `pri512@e020`（eval500 0.332）。rou64@e015 领先 +1.40pp 不显著（p=0.52、<2pp 门槛）⇒ 按 §7.10-A2 判"不稳定"，取证据更完整的 pri512。

3. **但发现强耦合修正（V1）**：ds 拉伸（几何×配速耦合）**单调抬升至峰值 0.778@s1.30**（timeout 0.236→0.086！），代价为 collision 上升（0.020→0.080，仍 ≤IDM 0.144）；s135/s140 过峰回落（s140 coll 0.158 越 IDM）。**s120–130 与 IDM 统计打平**（net +3/+10/+11，z=0.30/1.07/1.22，不显著），coll/off-road 优于 IDM、timeout 逊于 IDM。⇒ **可执行链上限带 = 0.75–0.80（<0.80）**；监督可追平 IDM，**超越仍需 RL 或更强教师**。
4. **正确性契约** = A 批探针 12 项落地（10 PASS + 2 顺延/覆盖）+ 三项流程发现（fail-fast 第三次拦截 / GL wrapper 纪律 / 引擎 run-to-run 非确定性地板及协议化）。

**战略含义（不粉饰）**：① 纯模仿"原始 D2"上限 ≈0.71；② "D2+V1 拉伸"变体 ≈0.78（与 IDM 打平）；③ G2（≥0.74）与 G3（≥0.80）的达成路径必须含 **RL 超教师**或**更强教师/配方**——P1-2 可加一个 gate 控制的 **pace-factor 监督实验**（见 §7.3）。
