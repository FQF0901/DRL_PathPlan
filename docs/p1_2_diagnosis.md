## 1. 摘要（结论链）

1. **现象**：`datasets/recovery_v1` 并入 phase3（mix 0.25）→ **闭环 1–2 epoch 内崩塌**（succ 0.34→0.01–0.07、off 49%→88–99%），而**离线 teacher-forced val 正常**（0.047）；**配方本身（无 recovery）稳定**（A2 0.30/0.31）。
2. **第一层根因（已修）**：recovery 行 80%（9,377/11,694）为**反事实错位对**（`step>takeover`：Pass-1 学生 obs × Pass-2 专家帧标签）。已加 `--phase3-recovery-row-filter takeover_only`（默认；提交 `37000ae`），可用对齐行 = 2,317。**过滤后仍崩** ⇒ 第二层存在。
3. **第二层根因（核心）**：受控离线探针证实——对齐行上模型 **4× 拟合专家目标**（action L1 0.320→0.080），且偏移是**状态条件化局部改写**：集中 **v∈[2,4) m/s**（Δds p50 +0.44~+0.57 m/步），base 分布各速度段 ≤+0.035（**无全局漂移**）。
4. **机制**：对齐集 90% 位于 2–4 m/s（失败/低速带）；专家目标 = "加速+回正"。**正常低速态（起步/弯道/环岛）与失败低速态在 obs 上不可分** ⇒ 恢复行为被学成低速带条件反射 → eval500 过冲出界；离线 val（88% ≥6 m/s）不可见 ⇒ 解释"离线/闭环分裂"。
5. **四轴穷举（结论闭合）**：**剂量**（0.25/0.05/0.02）、**对齐**（全量/对齐）、**类别**（全量/correction+late）、**冻结**（recovery/recovery_experts/freeze=all）**全部失败**——仅"零/近零暴露"（A2 无 recovery；A7-e1 单 epoch 未达损伤阈）不崩。⇒ **剂量与数据清洗无法根治；必须做监督结构性修复**。

## 5. 机制解释（一句话）

**绝对目标恢复监督 × 状态不可分 × 高倍过采样**（2,317 行 × ~40×/epoch @0.25）⇒ 失败态行为被写进整个低速带 ⇒ 正常低速驾驶（起步/弯道/环岛）被改写为"加速+过冲" ⇒ 出界。

## 6. 修复候选（结构性；提请回合裁决）

1. **残差式监督**：目标 = "专家 − 基线模型"增量（只学恢复修正，不重写绝对行为）；推理端需双分支/锚点（或冻结基座 + 残差头）。确定性最高、成本中等。
2. **状态门控**：把 margin/footprint/进度/失败指标引入 obs 或条件头，使"是否需要恢复"可分；与 P1-3 几何标签天然协同；成本中高（obs/结构改动）。
3. **采集器 v2（数据侧）**：① k≥1 行保存 **Pass-2 obs**（同源帧）；② 对学生真实逐点做 counterfactual 重规划（N 状态 × N 接管）产多行同源样本；③ 类别/路型配额。修复"行级语义"从源头。
4. **对照复盘 v7p1 DAgger 成功路径**：IDM 教师 + **窗口全步** + 5k 锚（mild），曾 0.31→0.53——与本次差异（单步快照 + 25% 混采 + pure_pursuit 教师）值得推演，可能指向更稳的数据构造（窗口式同源 + 低权重锚）。
5. **（组合）**：A7-e1 证据（单 epoch 未达损伤阈）提示"**短暴露 + 强评测闸**"可作为小步验证协议，而非正式配方。
