## B. 结论：可作用点

1. **终局罚（首选）**：失败经济学由终局值主导（dense 差 ~0.6）；碰撞/出界分离仅 6.4，
   抬 `collision` 是直接、可解释、低设计风险的单变量。
2. **近碰 dense（后备）**：有可测但**弱且晚**的信号（窗内中位 ~−1.2 vs 终局 Δ10），且
   lead-only 覆盖 ~60%——只适合做后备机制，不宜首选。
3. **场景级**：新增碰撞分散于 curve/tollgate/ramp（无 >30% 类），不做场景专项臂；
   arm6/7（lane_boundary/center）维持 §9.1 降级决定。
4. **rc 中档**：降碰撞增量 ~3pt 的附带效应（A.6），属于 bundle 底座选择问题，不在本节臂。

## C. 候选设计（均在 arm0 bundle 之上单变量）

### 候选 A（首选）：`terminal_values.collision` −22 → −32（Δ=+10）

- **机制**：救援成功概率 p 的盈亏平衡门槛 9.0% → 20.2%；把"低成功率救援"从边际正收益翻成
  边际负收益，直接作用于 55 例救援撞的决策边界。碰撞仍为最差失败类（−31.4 vs 出界 −15.0）。
- **敏感性**：Δ10 ≈ 当前分离 6.4 的 1.56×；Δ24（A′）→ 30.4 = 4.75×；Δ<10 可能不足以
  跨过 22% 救援撞的 p 分布中段。
- **预期方向**：碰撞率下降、成功数可能回吐（交换率 1.83）——辅助闸分账。
- **风险**：① 切除过多冒险救援 → net 跌破 +20（主判据兜底）；② 稀疏终局信号靠 value 传播，
  u200 可能欠学习（监控 `train/episodes/termination_counts/collision` 与 probe）。
- **成本**：≈45–55 min/臂实测（训练 ≈19 min + 子集闸 + keep-best + 全量/eval500 终评）；
  预注册上限 1.5–2 h/臂（含复检/失败处置）。

### 候选 A′（条件升级档）：`collision` −22 → −46（Δ=+24，= max_step 终局档）

- **触发（预注册）**：仅当 A 主判据通过（clean500 net ≥ +20 且 z ≥ 1.96）但辅助碰撞闸未过、
  且 A 的 clean500 碰撞率 ≤15.0%（相对 arm0 16.8% 有剂量响应）时执行；否则不跑。
- **机制**：碰撞总罚 ≈ −45.4 vs 出界 −15.0（分离 30.4 = 4.75×）；raw 终局与 max_step 等值。
- **风险**：与 max_step 在 raw 终局上不可分（total 仍差 30+，因 max_step dense +33.9）；
  过强或诱发保守/超时行为。

### 候选 B（后备）：`lead_gap` dense（weight −1.0 / gap_ref 6.0 m / cap 1.0）

- **机制**：`raw = clamp((gap_ref−gap)/gap_ref,0,1)`，**不要求接近速度**（等速跟车/减速接近
  也触发）——补 `ttc` 近零激活的空缺；临界前 ~2–4 步给"近距"本身计罚。
- **预期方向**：弱正效应（窗内均 −1.46）；只在前车近距场景生效（~60% 碰撞窗）。
- **风险**：① lead-only 视野不覆盖侧碰/切入门；② 信号弱可能不显著；③ 近距罚或诱发跟车
  退缩/爬行（arm4 λ0.98 前例）→ 监控 `low_speed`/crawl/max_step 与 net。
- **成本**：同 A（≈45–55 min；上限 1.5–2 h）。

**推荐首选：A（−32）**。理由：失败经济学指向终局；A 的单变量面最小（一个整数）、无新吸引子、
可剂量升级（A′）、失败可解释（net 回吐 vs 碰撞下降可归因）。B 仅在 A 主判据失败时启用。

## D. 判据 / 顺序 / 止损 / 预算（与 §7.5 一致）

- **开跑前置**：§9.1 seed=11 复现闭环完成后；P5 扩量挂在本节臂结果后。
- **主判据（§7.3）**：clean500 全量配对 net ≥ +20 且 z ≥ 1.96；eval500 同阈辅助；
  两集冲突记偏差、不判通过。
- **辅助碰撞闸（与主判据并列）**：clean500 相对 E-β″ 零点 `collΔ ≤ +3pt 或 碰撞率 ≤10%`；
  eval500 同口径辅助。arm0 实读 collΔ +10.8/+10.4pt = 要切除的缺口。
- **顺序**：A →（A′ 条件）→ B；A 主判据失败直接跳 B；B 失败 → 停线保留 bundle 结论。
- **止损修订**：u50 单点闸假阳性 3/4（A.6）⇒ 改 u50+u100 双点（均触发 net<−20 或
  offΔ≥+0.10 才停）或 u200 sub150 复检 + 全量复评；保留现场。
- **预算**：每臂 ≈45–55 min 实测，预注册按 ≤1.5–2 h 上限。

## E. 风险与限制

- 单 seed / 单子集读数为方向性；任何采纳须过 seed=11 复现（§9.1 三分法）。
- A/A′ 是"价格杠杆"：若救援撞的 p 分布与成功救援高度纠缠，净成功回吐可能 ≥ 碰撞收益
  （辅助闸正是为此设"或 ≤10%"的绝对下限）。
- B 的 would-be 统计来自 E-β″ 归档池（非 arm0 新碰撞集，后者无逐步 ctx 归档）——覆盖/量级
  为近似；实际臂须按 §7.4 收尾断言 extra 项均值 ≠ 0 验证激活。
- 诊断未做碰撞对象类型（车/物）分解（episodes.csv 无该字段）——lead_gap 项的侧碰盲区只能
  由 A/B 结果反证。
