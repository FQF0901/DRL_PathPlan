## 7. 归因判定

- "轨迹混沌（同分布不同样本、无系统性通道异常）"：**成立**——无任何通道爆炸/塌缩；权重线性分叉；
  分歧方向部分独立；行为差符号在训练中途翻转（u50 时 s11 更快、u200 时 s11 更慢），符合游走而非单调漂移。
- "系统性不稳定（某通道爆炸 / 熵塌 / 基线漂移）"：**不成立**——无 NaN/Inf；grad/KL/value loss 无趋势性分离；
  entropy 双向变化且均在各 run 历史范围内（s0 曾达 1.82、s11 曾达 1.68）；advantage 均值无漂移；router 稳定。
- 但**不是"围绕同一均值的温和 seed 噪声"**：两 run 落入不同吸引子，终局差超过同批混沌标尺。
  单 seed 结论（arm0 +99/+91）不可外推。

## 8. §9.1 / P5 / v7 含义

### §9.1 分类
- **正式判据（clean500）**：seed11 u200 net -59（z=5.00）（fixed/broken 40/99），远低于 −10 → **失败**；
  sub150 代理 u150/u175/u200 = −30/−28/−19 同向。eval500 未跑（"复现成立"已排除，非必需）。
  → 落 **失败 ⇒ 停线归因** 分支。
- 归因结论：不是 bug / 配置 / 通道故障，而是训练过程对采样噪声敏感导致的**吸引子分叉**；
  arm0 的 +99/+91 是单 seed 高侧抽样，2 seed clean500 样本均值已降至 ~+20（(+99−59)/2），
  bundle 臂真实期望远低于单 seed +99，不能以 arm0 单点作采纳依据。

### P5
- **阻断**（§8 本身要求"崩解修复为前提"；当前连复现都未过，且晚段吸引子分叉属于崩解范畴）。
  数据扩量（steps 100→200/400、distinct 500→5k）不得以 arm0 单 seed 正向为据启动。

### v7 建议
1. **多 seed 强制**：每臂 n≥3–5（至少 0/11/23），报分布（min/median/max）与分层；单 seed 不判通过/失败以外的结论。
2. **方差控制候选**（按优先级）：
   - KL 锚**末值 > 0**（如 0.01–0.02）或更慢衰减——u100–140 放大窗口与锚系数衰减期重合（u100 时 coef≈0.025，
     u150≈0.013），三条轨迹都在锚弱化后分叉；
   - 增大 rollout/等效 batch（当前 1 env × 256 steps/update，梯度噪声大；可 update 间累积多条 rollout）；
   - 评估协议：u50 单点闸假阳性 3/4（§7.5），seed11 是真阳性但机制中途翻转 → 保留 **u50+u100 双点** +
     keep-best（多 ckpt 按验证集选）；另加 EV/entropy 晚段监控（诊断用，非闸）；
   - 臂间比较：同 seed 配对不保证可比（arm5 与 arm0 同 seed 仍分叉）；需多种子平均或配对评估 + 置信区间。
3. **预注册精度假设修正**：单 seed 净效应精度 ±20–30 counts 仅适用于同吸引子内扰动；跨吸引子分叉可达 100+ counts。
   功效分析按最坏情况（bimodal）设计。
4. 保留现场策略正确（本批每 25 update ckpt 已足够事后吸引子归因）；后续臂沿用。
