# net

目的：策略网络与模型组件。

## 结构
- 主干隐藏维 H=96。
- 时序：GRU 编码 6 帧历史。
- 空间：2 层消息传递（OD / LD）。
- MoE：主专家常开、不受路由门控；8 个专家 96→192→96、零初始化残差；
  sigmoid 路由器，用逐步可观测标签做多标签 BCE 监督。
- 世界模型：ego 条件化的 OD/LD 动力学，6 步 rollout，直接多步损失。
- 策略头：输出 (ds, dtheta)；rollout 为策略自回归 ×6（方案 B1）。

## 参数预算
H=96、8×(96→192→96) 下主干合计约 585K 参数。

## 可插拔
编码器 / 专家 / 世界模型为独立模块，按配置装配。
